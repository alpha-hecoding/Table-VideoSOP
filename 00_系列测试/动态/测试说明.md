# 动态测试 01 — 候选A 视觉 + 克制运动

## 本测试解决什么判断

1. **入场节奏**：品牌 → kicker → 标题 → 下划线（宽度生长）→ 副题 → 芯片 → 双面板，全部"淡入 + ≤20px 上浮"，单步 0.5–0.7s，错峰 6–10 帧。判断：入场是否太快/太慢、与参考视频的安静感是否一致。
2. **形态变换语言**：标题下划线 0→120px 生长；右侧虚线路径按 x 方向渐进揭示（inOut 曲线）。判断："沿线生长"作为系列形态变换语言是否可用。
3. **对象交互 + 时间对比**：同一"感知→答案"对象在左右两条路线出现：左直线 0.6s（快、inOut），右折线 1.13s（匀速、逐步）。判断：不靠旁白，时间差与轨迹差能否传达"快速直觉 vs 慢速反思"。
4. **接触反馈**：左点到达答案盒时盒子离散换态（白框→浅橙框橙边）并 1.05 脉冲，JEVA 标签入场；右点到达时边框墨色加粗 0.2s 后回落。判断：状态反馈幅度是否合适，终态是否与已确认静态帧一致。
5. **数据揭示**：三张卡 8 帧错峰上浮，数字 2s ease-out 从 0 计到 9,000+ / 852 / 266。判断：计数的可读性与数据段节奏。
6. **结果停稳**：最后 2.8s 无运动，终帧与静态候选A（Noto 版）一致。判断：阅读停稳时间是否够、终态是否一致。

## 参数

全部集中在 `工程/src/MotionTest.tsx` 的 `T` 表（30fps，总 300 帧 = 10s，1920×1080）：

- 曲线约定：入场/下划线/计数用 `Easing.out(cubic)`；路径揭示与左点直线用 `Easing.inOut`；右折线匀速（linear，强调"稳"）。
- 右折线按弧长参数化（`pointAt`）；接触脉冲幅度 1.05 / 1.04，时长 0.4s。
- 终帧所有状态（盒色、边框、数字、页脚）与静态候选一致。

## 验证方式

- 预览：`动态预览_测试01.mp4`（本目录）
- 源码：`工程/`（`pnpm dev` 可开 Remotion Studio 逐帧查看）
- 动态自检：`tools/motion-check.sh` 输出见本目录 `自检/`（只定位问题，不判通过）

## 结果

- 2026-10-15 渲染成功（300 帧 @30fps，497 kB）；抽帧复核：
  - 0.35s / 1.7s：入场顺序与节奏（品牌→kicker→标题→下划线生长→副题→芯片→面板）
  - 2.7s / 3.2s：左点 0.6s 直线到达，答案盒接触后白框→浅橙框，JEVA 入场
  - 4.0s / 4.35s：右点 1.13s 匀速走完全折线，接触后墨色边框加粗 0.2s 回落
  - 5.8s：数字计数中（8,268+ / 783 / 244）
  - 9.7s：终帧与静态候选A（Noto 版）一致
- 动态自检（tools/motion-check.sh，输出在 自检/）：定位三个低运动区间 2.40–4.27s、5.10–8.33s、8.33–10.00s，均为小面积运动（圆点、数字）或有意的结果停稳（末尾 2.8s 阅读），未见空白画面或过程缺失
