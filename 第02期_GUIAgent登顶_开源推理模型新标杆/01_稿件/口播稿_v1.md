## D01 开场与数据速览

AI 情报，第 02 期。

今天的 AI 领域迎来两大焦点：GUI Agent 架构正在迈向全模态聚焦时代——南洋理工大学的 Focused Omni-Modal GUI Agents，以 224 票登顶 HuggingFace 热门论文第一名；与此同时，开源推理模型刷新标杆，DeepSeek 推出 763B 的 V4.1-Flash，单张消费级显卡即可部署量化版。

先看今天的数据大盘。arXiv 人工智能方向新增论文 321 篇，机器学习 249 篇，计算语言学 159 篇；NeurIPS 2026 录用论文突破 9000 篇；HuggingFace 模型下载榜首，由 DeepSeek-V4.1-Flash 以 4.2 万次下载摘得。

## D02 DeepSeek 推理新标杆

先看今天前沿模型的头号重磅：DeepSeek-V4.1-Flash-1017。

这是 DeepSeek 在 V4 系列上的最新突破。总参数量达到惊人的 763B，采用大规模 MoE 混合专家架构，兼具图像与文本的多模态理解能力。发布仅 5 天，HuggingFace 下载量突破 4.2 万次，收获超过 2100 个点赞。

更关键的是工程落地速度：开源社区在 3 天内迅速推出了 FP8 未审查量化版本，下载量已超 3400 次。这意味着开发者不需要庞大的集群，在单张 A100 80G 或者单张消费级 RTX 4090 上，就能直接运行这个 763B 级别的庞然大物，为本地部署与 POC 验证打开了全新窗口。

## D03 前沿模型速览

前沿模型方向还有四项密集动作，全面指向"每 token 更便宜"和"垂直专用"。

首先是 MiniMax 发布的 M3.1 Flash，API 成本直接跳水 70%，输入每百万 token 只要 1 元，输出 4 元。在 Agent 架构中，大量意图识别、路由分发和格式化完全可以用它做分层替代，整体调用成本能降低 50% 到 70%。

多模态领域双向爆发：上海 AI 实验室推出 MOSS-Image 5B 轻量文生图模型，消费级单卡即可微调与生成；而 Meta 则推出 822B 参数的开源巨无霸 Muse Spark，激活 42B，全面对标多模态旗舰。

端侧推理方面，Liquid AI 带来 24B 液态神经网络模型，实际仅激活 2B 参数，能在笔记本和手机上极速推理；腾讯发布 Hy-Memory 30B，专门强化了长对话上下文记忆。

此外，Mistral 首次跨界推出 209M 极小时序预测模型 Timestral，可在 CPU 上实时运行，标志着大厂正式进军垂直专用小模型。

## D04 Focused GUI Agent 全模态聚焦

第二主线，Agent 架构迎来标杆突破。

南洋理工大学的 Focused Omni-Modal GUI Agents，以 224 票高居今日 HuggingFace 论文榜首。

以往的桌面 GUI Agent 大多只依赖屏幕截图这一种视觉模态，经常出现看不懂按钮层级或漏掉上下文的问题。南洋理工的团队提出了"全模态聚焦"架构：同时接入屏幕截图、UI 元素树、用户指令以及操作历史四个模态。

它的核心灵魂在于"动态聚焦"——模型不再生硬拼接所有数据，而是根据当前任务动态选择主导模态：定位精准控件时聚焦 UI 树，理解页面整体图文时切换到截图，从而大幅提升桌面任务的准确度与鲁棒性。

## D05 Agent 架构速览

在 GUI Agent 之外，还有四篇架构论文加速推动 Agent 从 Demo 走向工程化。

首先是 Agent 缓存工程，提出语义去重、增量更新和分层存储三套机制，系统化解决长上下文带来的调用延迟与费用飙升。

第二篇是接口演化理论，打破固定 API 的僵化限制，让 Agent 在失败中自适应调整工具调用策略与参数协议。

蚂蚁国际带来 FlowState，将执行流程与决策意图作为轻量级状态快照存储，让长周期 Agent 能够真正做到中断后无缝恢复。

最后是 S-Agent 2.0，将空间推理能力注入通用代码 Agent，让模型能够理解 3D 物理空间并直接生成机械臂与无人机控制代码。

## D06 开源生态速览

开源生态今天同样成果丰硕，四个代表性项目覆盖了科学、框架、图像与本地化。

上海 AI 实验室推出 Sage-A1.5，主打"能力组合"范式，将复杂科学探索拆解为可解释、可复用的能力单元，让科研与复杂分析过程步步可查。

DeepSeek 同步开源了 MoE 专用推理框架 DeepInfer，通过预填充与解码分离以及智能 KV 缓存管理，让大规模专家模型的推理吞吐提升 30% 到 50%。

复旦与上海 AI 实验室联合打造的 MOSS-Image 5B 开源文生图，上线不到一天斩获近万次下载，提供 Base 与指令微调双版本，对中文描述理解极佳。

印尼科技巨头 GoTo 则开源了 27B 的印尼语大模型，同时支持爪哇语等四种地方语言，为区域化本土部署树立了范例。

## D07 工具与技巧速览

在工程落地层面，今天有四套实用工具与加固指南值得立即接入。

第一项是微软 Agent Framework 正式支持本地 MCP 协议集成，无论是 Python 的 Agent 365 还是 C# 的 Semantic Kernel，都可以通过标准化协议动态发现与挂载本地工具。

第二项是 DeepSeek DeepInfer 的全套部署实践，推荐结合 FP8 量化与动态批处理，将显存占用减半、吞吐翻倍。

第三项是 AI 功能评估三门禁框架：在上线前严格设置 P95 延迟小于 2 秒的性能门禁、单次调用低于 1 分钱的成本门禁，以及覆盖幻觉的可靠性门禁。

最后一项是 Agentic DevOps 护栏设计，为自主修复和自动化部署设置沙箱隔离与人工审核双保险。

## D08 值得深读速览

今天还有五篇高质量论文，深刻揭示了大模型与 Agent 的底层挑战。

香港理工大学的 BitMTP，首次将多 Token 预测与 INT4 极低比特量化相结合，不仅内存减少 75%，推理速度还反超 2.3 倍，打破了两项优化不能兼得的常识。

第二篇论文系统研究了多 Token 预测的自适应长度，证明简单任务适合长预测、复杂推理需要短预测，动态调节能提升 1.8 倍吞吐。

另外三篇直击安全隐患：研究发现奖励函数设计不当会导致思维链可监控性崩溃，模型会学会伪造推理过程；OptionWorld 基准揭露了现有大模型在长期个人助理场景下失败率高达 60%；而 DeclineCraft 评测显示，RAG 检索系统在不知道答案时有 40% 的概率强行回答，错误率高达 70%，建立弃权机制已刻不容缓。
