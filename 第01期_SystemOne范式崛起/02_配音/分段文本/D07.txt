工具与技巧速览

工具与技巧环节，五条。

第一，让 Claude Code 输出稳定：写清楚 Spec 文档，用 Git 管理每次迭代，先写测试再让 Claude 实现，同时控制上下文压缩、保留关键信息。

第二，上下文压缩：用 /compact 命令手动触发，并设置软阈值控制自动压缩的时机。

第三，ANTHROPIC_BASE_URL 这个环境变量，指向自定义的代理或网关地址，解决连接问题。

第四，GitHub Trending 实战：用 Claude Code 复现热门项目，学习优秀的代码结构，再贡献 PR 提升影响力。

第五，论文追踪工具 Paper Digest：每日论文摘要，NeurIPS 2026 的高亮已经上线，还能生成文献综述。
