## D02 Jeva System One 范式

先看今天的头号论文：Jeva，全名 System One Models from First Principles，来自新加坡国立大学。

这篇论文借鉴认知科学的"系统 1 / 系统 2"理论，构建了一个快速、直觉式的推理模型。不同于传统思维链的慢思考路径，Jeva 追求的是"一眼看穿"的即时推理。

架构上，它不是在现有 Transformer 上打补丁，而是从第一性原理出发重新设计，采用新型注意力机制，减少推理步骤。

效果是：在数学、代码和常识推理任务上达到 GPT-4 级别，但推理速度快 3 到 5 倍；模型规模约 35B，适中，适合部署。

## D03 前沿模型速览

前沿模型方面还有几个密集动作。

Liquid AI 发布了 LFM2.5-24B-A2B，端侧大模型的新标杆：总参数 24B，但靠 MoE 混合专家架构，实际推理只激活 2B 参数，支持图像和文本多模态，可以在手机和笔记本上流畅运行。对比一下：Qwen3.8-27B 是 27B 全激活，MiniCPM-V 4.7 是 35B 总参、3B 激活，Phi-4 有 14B 但不支持多模态——LFM2.5 的端侧友好度明显领先。

Qwen 家族持续迭代：图像生成加速版 Image-2.1-Turbo 速度提升 40%，质量不降；多模态旗舰 Qwen3.8-27B 下载量 722 万；还有 180B 的超大杯 Flash-Next，对标 GPT-4 和 Gemini Ultra。

Meta 在 10 月 12 日发布 Muse Wonder，两个亮点：主动记忆，跨对话保留上下文，不再失忆；主动专注，长时间任务不跑偏，持续追踪目标。它在部分任务上超越竞品，但高风险领域仍有安全顾虑，Meta 承诺发布完整安全报告。

另外，Google 发布 Gemini 4 系列新变体 Gemini 4 Argon，延续多模态能力，具体细节待官方公布。

## D04 Agent-Reflex 反思闭环

第二主线，Agent 架构。

中国人民大学的 Agent-Reflex，教 Agent 学会"反思"，HuggingFace 上 193 票。思路很直接：Agent 不只是执行，还要在执行之后反思结果——行动、观察、反思、调整策略，类似人类的复盘。它的架构在感知、规划、行动、观察结果之外加入反思模块，把策略更新回灌到循环里，形成一个完整闭环。

实验效果：在 WebShop、ALFWorld 等基准上提升 15% 到 20%，错误恢复能力显著增强，无效行动次数减少。

## D05 Agent 架构速览

Agent 架构方向还有四篇值得一看。

Self-Evolving Agent Harness：Agent 不只执行任务，还能从执行中学习，自动提取经验、更新自身策略，实现无需人工干预的持续进化——这和只推理行动的 ReAct、策略固定的 Reflexion 不一样。

Google 的 Harness 平方：Agent 可以编排其他 Agent，形成递归结构，支持开放世界任务，类似"元 Agent"，适合复杂项目管理和多 Agent 协作。

Pack Light, CarryOn：解决长程任务的上下文难题——把信息封装成对象，按需加载、动态压缩，保留关键、丢弃冗余。

BLADE：多 Agent 系统出错时，审计每个 Agent 的信息使用，追踪信息流动路径，精确定位故障源头。

## D06 开源生态速览

开源生态，八个项目速览。

OpenBMB 的 MiniCPM-V 4.7，35B 总参、3B 激活的 MoE 多模态模型，移动端图像理解和离线 OCR 很实用，还有超轻量的 1B 版本，手机可跑。

百度的 Unlimited-OCR，下载量超过 115 万，支持无限长度文档，中英文混合识别是顶级水平。

Lightricks 的 LTX-2.5，图像生成视频，下载量 182 万，适合短视频创作。

fishaudio 的 drama-3，36B 的超大规模语音合成，情感丰富、支持多语言。

speridlabs 的 iris-3b，轻量图像生成，端侧可运行、速度快。

Cloudflare 的 clef，边缘部署优化的多模态理解模型。

最后是 Google 官方嵌入模型 embeddinggemma-2，只有 0.7B，下载量 13.5 万，适合检索和相似度计算。

## D07 工具与技巧速览

工具与技巧环节，五条。

第一，让 Claude Code 输出稳定：写清楚 Spec 文档，用 Git 管理每次迭代，先写测试再让 Claude 实现，同时控制上下文压缩、保留关键信息。

第二，上下文压缩：用 /compact 命令手动触发，并设置软阈值控制自动压缩的时机。

第三，ANTHROPIC_BASE_URL 这个环境变量，指向自定义的代理或网关地址，解决连接问题。

第四，GitHub Trending 实战：用 Claude Code 复现热门项目，学习优秀的代码结构，再贡献 PR 提升影响力。

第五，论文追踪工具 Paper Digest：每日论文摘要，NeurIPS 2026 的高亮已经上线，还能生成文献综述。

## D08 值得深读速览

值得深读的，五篇。

UCLA 的 Tev，用密集进度奖励解决长程任务的稀疏奖励问题，环境可以扩展到数千步任务，在 WebShop、ALFWorld 上做到 SOTA。

TPPO 改进 PPO 算法，引入 Tracking-Value，让每个 token 的贡献评估更精确，数学和代码推理提升 10% 到 15%，训练更稳定、收敛更快。

Vela 把用户行为——点击、停留、修改——变成监督信号，不需要人工标注，从真实交互里持续学习。

Hybrid Reasoning Agents 和今天主题最相关：把 System 1 的快速直觉和 System 2 的慢速推理结合起来，动态选择推理模式，效率和准确率兼得，被认为是未来 Agent 的标准架构。

DoubtLess 用对比解码，无需训练、即插即用，推理速度提升 2 到 3 倍，质量不降。
