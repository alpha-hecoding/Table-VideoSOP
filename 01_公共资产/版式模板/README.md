来源：AI情报 第01期（2026-10-19 随全片视觉总览 v1 确认，用户"全部默认"）。这四套版式是**跨期复用**的框架帧，不是本期专属；改动须走期末复盘，不在单期内顺手改。

视觉参数一律以根目录 `DESIGN.md`（revision 1.0.0）为准；本目录的 HTML 只是已确认版式的可渲染样例，其中的字色、字号、间距若与 DESIGN 冲突，以 DESIGN 为准并回报差异。

## 用法

- 直接改 HTML 内的文字字段渲染，不改结构、配色与组件参数；需要新版式时先出候选交用户确认，再入本目录。
- 干净版＝默认打开；标注版＝URL 加 `#annot`。标注层含第01期的段号引用（D04/D05 等），只作来源线索，不属于上屏内容。
- 渲染：`google-chrome --headless --no-sandbox --screenshot=OUT.png --window-size=1920,1080 --virtual-time-budget=4000 FILE`；`#measure` 可导出关键盒子的实测坐标，用于跨期比对是否走形。
- 顶栏（栏目名＋EP＋日期）与页脚属内容帧外壳：顶栏恒定承接不重绘；页脚右段两种口径（来源型／章位型）同帧不混用。

## 尚未验证（不要外推）

- 章卡与片尾卡的动态入场未单独做样片：本期按已确认入场语言（淡入＋≤20px 上浮、错峰 6–8f）实现，成片后复核。
- 换期题长度（h1 换行、字数明显超出本期样本）时须重新检查裁切与安全区，不假定自动适配。
- 竖版或其他画幅不套用本目录版式，按 DESIGN 重新布局。
